**2002AA29**는 지구근접소행성(NEA)으로, 먼 미래에 지구의 준위성이 될 것으로 예측되는 천체이다. 이 천체는 주기적으로 지구와 매우 가까워지기도 하며 준위성 시기에는 특히 최근접 상태를 오랫동안 유지하기도 하므로 탐사선을 보내기에 어렵지 않을 것으로 판단, 2002AA29로의 탐사 미션을 계획해보는 프로젝트를 진행하였다.

## 2체 문제에서의 탐사 궤적 최적화
### 람베르트 문제
첫 최근접 시기인 2100년경에 탐사 임무를 설정하는 것이 가장 효율적일 것이라고 판단하였다. 먼저 간단한 2체 Lambert 문제를 풂으로써 지구에서 출발해 2002AA29까지 도달하는 궤적을 도출할 수 있었다. Lambert 문제는 중심천체의 $\mu$, 출발 시점에서의 위치벡터 $\mathbf{r}(t_1)$과 도착 시점에서의 위치벡터 $\mathbf{r}(t_2)$, 그리고 비행시간 $\Delta t=t_2-t_1$을 통해 궤도를 특정하는 문제이다.

Solver는 Python의 lamberthub에서 제공하는 것 중 `gooding1990`을 이용하였고, revolution은 0회로 설정하였다. 

```python
v_sc_dep, v_sc_arr = gooding1990(
    mu,
    earth_dep.r,
    target_arr.r,
    tof_days,
    M=0,
    prograde=True,
    low_path=True,
)

vinf_dep_vec = v_sc_dep - earth_dep.v
vinf_arr_vec = v_sc_arr - target_arr.v

c3 = np.linalg.norm(vinf_dep_vec_km_s)**2 # 출발 C3
vinf_arr = np.linalg.norm(vinf_arr_vec) # 도착 초과속도
```

2090년부터 2110년까지의 NASA JPL Horizons 데이터를 호출한 뒤 해당 일자 중 TOF가 30일부터 730일까지의 기간을 갖도록 출발 시기와 도착 시기를 바꿔가며 5일 간격으로 계산하였다. 그 결과 그려진 $C_3$와 도착 $v_\infty$ 산점도는 아래와 같다.

산점도 전면에 명확한 front가 관찰되는 모습으로, 여기서 $C_3$는 $0\sim30\;\mathrm{km^2/s^2}$의 범위를 가지며, 도착 $v_\infty$는 이와 trade-off 관계로 $0\sim 6\;\mathrm{km/s}$까지의 범위를 가지는 것으로 관찰되었다. 또한, front에 가까운 영역에 TOF가 짧은 해들이 몰려있는 것 또한 관찰되었다.

ULA의 Vulcan Centaur는 화성행 미션의 $C_3$를 $20\;\mathrm{km^2/s^2}$ 정도로 잡고 있으므로, 이와 같은 고에너지 지구탈출 케이스와 비교하기 위해 이를 이번 미션의 상한값으로 설정하였다. 따라서 front에서 $C_3=10,15,20\;\mathrm{km^2/s^2}$인 경우를 대푯값으로 선정하여 해당 기간을 1일 간격으로 재계산하였고, 그 결과에서 $C_3\le20$인 경우 중 $v_\infty$가 최소인 값을 선정하였다.

### 탈출 쌍곡선 궤도 계산
쌍곡선 궤도를 따라 비행하는 탐사선은 탈출 후 충분한 시간이 흐르면 그 속도가 초과속도 $\mathbf{v}_\infty$에 수렴하며, 이때의 진근점이각은 다음과 같다.

$$f_\infty=\arccos\left(-\frac{1}{e}\right)$$

따라서 $$\hat{\mathbf{s}}=\mathbf{v}_\infty/\lVert\mathbf{v}_\infty\rVert$$를 궤도면 법선 $\hat{\mathbf{h}}$에 관해 $-f_\infty$만큼 회전시키면 근지점 위치 단위벡터 $\hat{\mathbf{r}}_p$를 구할 수 있다. 이어서 근지점 속도 단위벡터는 $\hat{\mathbf{v}}_p=\hat{\mathbf{h}}\times\hat{\mathbf{r}}_p$로 얻으며, 그 크기는 에너지 보존으로 구할 수 있다.

$$v_p=\sqrt{v_\infty^2+\frac{2\mu_\oplus}{r_p}}$$

이는 다음과 같이 구현하였다.

```python
def rodrigues(vector, axis, angle_rad):
    axis = unit(axis)

    return (
        vector * np.cos(angle_rad)
        + np.cross(axis, vector) * np.sin(angle_rad)
        + axis * np.dot(axis, vector) * (1 - np.cos(angle_rad))
    )

# 초과속도
vinf = np.linalg.norm(vinf_dep_vec)
s_hat = unit(vinf_dep_vec)

# 지구 탈출 쌍곡선
r_p = R_EARTH + park_alt_km
e = 1 + r_p * vinf**2 / MU_EARTH
f = np.arccos(-1 / e)

reference = np.array([0.0, 0.0, 1.0])
h_hat = unit(np.cross(s_hat, reference))

# 근지점
r_hat_p = rodrigues(s_hat, h_hat, -f) # 위치벡터 방향
r_p_vec = r_p * r_hat_p # 위치벡터

v_hat_p = unit(np.cross(h_hat, r_hat_p)) # 속도벡터 방향
v_hyp_p = np.sqrt(vinf**2 + 2 * MU_EARTH / r_p) # 속도벡터 크기
v_hyp_p_vec = v_hyp_p * v_hat_p # 속도벡터

v_circ = np.sqrt(MU_EARTH / r_p) # 케플러 속도
v_park_vec = v_circ * v_hat_p # 주차궤도 속도벡터
delta_v_inj_vec = v_hyp_p_vec - v_park_vec # injection 시 Delta V
```

여기서 주차궤도는 고도 200 km의 LEO로 설정하였다. 그러나 이를 통해 출력된 값을 그대로 초기값으로 하여 수치적분에 활용하기에는 지구와 너무 가까워 문제가 있었다. 이를 해결하기 위해 지구의 SOI까지 전파시킨 후 활용하기로 하였다. 최초 람베르트 해로 설정한 지구 탈출 쌍곡선 궤도를 따르면 약 JD 2487524.73에 SOI에 도달하는 것으로 분석되었으며, 이 시점을 기준 시간으로 잡았다. 

## 수치적분을 통한 도착 오차 분석
도착 오차를 개선하기 위해 다음과 같은 방법을 이용하였다. 먼저 근지점에서의 normal, tangent 방향 속도와 위상을 각각 미소변화시켜 기준 시간까지 전파한 후 이를 초기값으로 하여 수치적분하였다.

```python
# 위상 시험값 반영
h_hat = escape["h_hat"]

# 로드리게스 회전 공식 사용
r_p_km = rodrigues(
    escape["r_p_km"],
    h_hat,
    phase_rad,
)

v_hyp_p_km_s = rodrigues(
    escape["v_hyp_p_km_s"],
    h_hat,
    phase_rad,
)

v_park_km_s = rodrigues(
    escape["v_park_km_s"],
    h_hat,
    phase_rad,
)

r_hat_p = unit(r_p_km)
t_hat_p = unit(v_hyp_p_km_s)
n_hat_p = unit(np.cross(r_hat_p, t_hat_p))

# tangent, normal 시험값 반영
dv_burn_km_s = (
    dv_tangent_km_s * t_hat_p
    + dv_normal_km_s * n_hat_p
)

v_after_burn_km_s = v_hyp_p_km_s + dv_burn_km_s

# 기준 시간까지 전파한 값을 mercury6 초기값으로 사용
def propagate_to_fixed_time(
    r0_km,
    v0_km_s,
    tof_s,
):
    y0 = np.hstack((r0_km, v0_km_s))

    def rhs(_, y):
        r = y[:3]
        v = y[3:]

        a = -MU_EARTH * r / np.linalg.norm(r)**3

        return np.hstack((v, a))

    solution = solve_ivp(
        rhs,
        (0.0, tof_s),
        y0,
        method="DOP853",
        rtol=1e-12,
        atol=1e-10,
        dense_output=True,
    )

    return {
        "r_km": solution.y[:3, -1],
        "v_km_s": solution.y[3:, -1],
        "solution": solution,
    }

handoff = propagate_to_fixed_time(
    r_p_km,
    v_after_burn_km_s,
    HANDOFF_TOF_S,
)

r_handoff_au = (
    earth_soi_state.r
    + handoff["r_km"] / AU_KM
)

v_handoff_au_day = (
    earth_soi_state.v
    + handoff["v_km_s"] * DAY_S / AU_KM
)
```

얻은 결과를 이용해 야코비안을 구성하였고, 이를 통해 각 시행에서 사용할 값들을 도출하였다. 

```
def calculate_error(vec_sc, vec_aa29):
    df = vec_sc.merge(
        vec_aa29,
        on="time",
        suffixes=("_sc", "_aa29"),
    ).sort_values("time")

    return (
        df.iloc[-1][["x_sc", "y_sc", "z_sc"]].to_numpy()
        - df.iloc[-1][["x_aa29", "y_aa29", "z_aa29"]].to_numpy()
    )

dr = calculate_error(space_run1_vec, aa29_run1_vec)
dr_tangent = calculate_error(space_tangent_vec, aa29_run1_vec)
dr_normal = calculate_error(space_normal_vec, aa29_run1_vec)
dr_phase = calculate_error(space_phase_vec, aa29_run1_vec)

J0 = np.column_stack([
    (dr_tangent - dr) / DV_TEST_KM_S,
    (dr_normal - dr) / DV_TEST_KM_S,
    (dr_phase - dr) / PHASE_TEST_RAD,
])

du = np.linalg.solve(J0, -dr)
```

### 최초 실행
초기 궤적을 수치적분하여 얻은 결과, 도착 시점에서 탐사선과 2002 AA29 사이의 위치 오차는

$$\Delta\mathbf{r}_1=\begin{bmatrix}-75780.6 \\ -88927.6 \\ 159401.6\end{bmatrix}\;\mathrm{km}$$

였고, 그 크기는

$$\lVert\Delta\mathbf{r}_1\rVert=197635.2\;\mathrm{km}$$

였다. 도착 오차에 대한 각 설계변수의 민감도는 tangential 및 normal 속도, 그리고 위상에 각각 작은 섭동

$$\delta v_t=0.010\;\mathrm{m/s}, \quad\delta v_n=0.010\;\mathrm{m/s}, \quad\delta \phi=0.0-0057^\circ$$

을 가한 추가 계산을 통해 구하였다. 이를 이용해 계산한 1차 보정량은 다음과 같았다.

$$\begin{aligned}\Delta v_t&=-25.2721\;\mathrm{m/s}\\\Delta v_n&=42.8307\;\mathrm{m/s}\\\Delta \phi&=-0.583831^\circ\end{aligned}$$

### 2차 실행
1차 보정을 적용하여 다시 적분한 결과, 위치 오차는

$$\Delta\mathbf{r}_2=\begin{bmatrix}-12686.7 \\ -10471.9\\ 2095.1\end{bmatrix}\;\mathrm{km}$$

로 감소하였고, 그 크기는

$$\lVert\Delta\mathbf{r}_2\rVert=16583.2\;\mathrm{km}$$

였다. 여전히 오차가 충분히 작지 않으므로 동일한 방법으로 민감도를 다시 계산하여 다음 보정량을 얻었다.

$$\begin{aligned}\Delta v_t&=0.03163\;\mathrm{m/s}\\\Delta v_n&=0.74868\;\mathrm{m/s}\\\Delta \phi&=-0.005124^\circ\end{aligned}$$

### 3차 실행
2차 보정까지 적용한 후 다시 적분한 결과 위치오차는

$$\Delta\mathbf{r}_3=\begin{bmatrix}1.4831 \\ 0.2668 \\ -0.1666\end{bmatrix}\;\mathrm{km}$$

였고, 크기는

$$\lVert\Delta\mathbf{r}_3\rVert=1.516\;\mathrm{km}$$

까지 감소하였다.

따라서 최초 약 $1.98\times10^5\;\mathrm{km}$였던 도착 위치 오차를 세 차례의 궤도 계산과 두 차례의 differential correction을 통해 약 $1.52\;\mathrm{km}$까지 줄일 수 있었다.
