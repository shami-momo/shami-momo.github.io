**2002AA29**는 지구근접소행성(NEA)으로, 먼 미래에 지구의 준위성이 될 것으로 예측되는 천체이다. 이 천체는 주기적으로 지구와 매우 가까워지기도 하며 준위성 시기에는 특히 최근접 상태를 오랫동안 유지하기도 하므로 탐사선을 보내기에 어렵지 않을 것으로 판단, 2002AA29로의 탐사 미션을 계획해보는 프로젝트를 진행하였다.

먼저 100년 이하의 주기로 지구와 최근접하는 것으로 분석되었고, 이 과정에서 말발굽 궤도를 그린다. 최근접 시기마다 궤도 요소들이 계단식으로 변하다가 2577년경 지구의 준위성으로 편입되며, 이는 공명각이 0에서 진동하는 것으로 확인할 수 있었다. 여기서 준위성 단계의 시작과 끝에서 야코비 상수가 극값을 가지고, 준위성 단계에서는 다른 시기와 확연히 구분되는 선형적 감소를 보인다는 점에서 야코비 상수를 준위성 판단의 보조 지표로 활용할 수 있음을 보였다. 이후 2623년경 다시 말발굽 궤도로 돌아가게 된다.

## 2체 문제에서의 탐사 궤적 최적화
### 람베르트 문제
첫 최근접 시기인 2100년경에 탐사 임무를 설정하는 것이 가장 효율적일 것이라고 판단하였다. 먼저 간단한 2체 Lambert 문제를 풂으로써 지구에서 출발해 2002AA29까지 도달하는 궤적을 도출할 수 있었다. Lambert 문제는 중심천체의 $\mu$, 출발 시점에서의 위치벡터 $\mathbf{r}(t_1)$과 도착 시점에서의 위치벡터 $\mathbf{r}(t_2)$, 그리고 비행시간 $\Delta t=t_2-t_1$을 통해 궤도를 특정하는 문제이다.

Solver는 Python의 lamberthub에서 제공하는 것 중 `gooding1990`을 이용하였고, revolution은 0회로 설정하였다. 사용한 함수는 아래와 같다.

```python
def solve_lambert(
    earth_dep: StateVector,
    target_arr: StateVector,
    dep_jd: float,
    arr_jd: float,
    *,
    mu: float = MU_SUN,
) -> TransferResult:
    tof_days = float(arr_jd - dep_jd)

    v_sc_departure, v_sc_arrival = gooding1990(
        mu,
        earth_dep.r,
        target_arr.r,
        tof_days,
        M=0,
        prograde=True,
        low_path=True,
    )

    # 행성 기준 초과속도 벡터 [AU/day]
    vinf_dep_vec_au_day = v_sc_departure - earth_dep.v
    vinf_arr_vec_au_day = v_sc_arrival - target_arr.v

    # 벡터 전체를 km/s로 변환
    vinf_dep_vec_km_s = np.asarray(
        au_per_day_to_km_per_s(vinf_dep_vec_au_day),
        dtype=float,
    )
    vinf_arr_vec_km_s = np.asarray(
        au_per_day_to_km_per_s(vinf_arr_vec_au_day),
        dtype=float,
    )

    vinf_dep_km_s = float(np.linalg.norm(vinf_dep_vec_km_s))
    vinf_arr_km_s = float(np.linalg.norm(vinf_arr_vec_km_s))

    return TransferResult(
        v_dep=v_sc_departure,
        v_arr=v_sc_arrival,
        vinf_dep_vec=vinf_dep_vec_km_s,
        vinf_arr_vec=vinf_arr_vec_km_s,
        vinf_dep=vinf_dep_km_s,
        vinf_arr=vinf_arr_km_s,
        c3=vinf_dep_km_s**2,
        tof_days=tof_days,
    )
```

2090년부터 2110년까지의 NASA JPL Horizons 데이터를 호출한 뒤 해당 일자 중 TOF가 30일부터 730일까지의 기간을 갖도록 출발 시기와 도착 시기를 바꿔가며 5일 간격으로 계산하였다. 그 결과 그려진 $C_3$와 도착 $v_\infty$ 산점도는 아래와 같다.

산점도 전면에 명확한 front가 관찰되는 모습으로, 여기서 $C_3$는 0에 가까운 수치부터 30km²/s²의 범위를 가지며, 도착 $v_\infty$는 이와 trade-off 관계로 6km/s부터 0까지의 범위를 가지는 것으로 관찰되었다. 또한, front에 가까운 영역에 TOF가 짧은 해들이 몰려있는 것 또한 관찰되었다.

ULA의 Vulcan Centaur는 화성행 미션의 $C_3$를 20km²/s² 정도로 잡고 있으므로, 이와 같은 고에너지 지구탈출 케이스와 비교하기 위해 이를 이번 미션의 상한값으로 설정하였다. 따라서 front에서 $C_3$가 10, 15, 20km²/s²인 경우를 대푯값으로 선정하여 해당 기간을 1일 간격으로 재계산하였고, 그 결과에서 $C_3\le20$인 경우 중 $v_\infty$가 최소인 값을 선정하였다.

|---|---|---|---|---|
| JD 2487522.5 | JD 2487737.5 | 215.0 days | 19.787771 km²/s² | 1.171324 km/s |

### 탈출 쌍곡선 궤도 계산
쌍곡선 궤도를 비행하는 탐사선이 초과속도($v_\infty$)에 가까워질 때의 비행각은 기준각에 대해 다음과 같다.

$$\theta_\infty=\arccos\left(-\frac{1}{e}\right)$$

따라서 $v_\infty$의 단위벡터를 $-\theta_\infty$만큼 회전시키면 근지점에서의 속도단위벡터를 구할 수 있고, 그 크기는 활력방정식으로 구할 수 있다. 이를 구현한 코드는 아래와 같다.

```python
def make_escape_hyperbola(
    vinf_dep_vec,
    parking_alt_km,
    h_hat=None,
):
    # vinf_dep_vec : ndarray, shape (3,) / Lambert 해에서 얻은 지구 기준 출력 초과속도 벡터 [km/s]
    # parking_alt_km : float / 주차궤도 고도 [km]
    # h_hat : ndarray, shape (3,), optional / 탈출 쌍곡선 궤도면의 법선 단위벡터 (none이면 임의)
    
    vinf = np.linalg.norm(vinf_dep_vec)
    s_hat = unit(vinf_dep_vec)

    # 궤도 평면
    if h_hat is None:
        reference = np.array([0.0, 0.0, 1.0])

        # vinf가 z축과 거의 평행하면 다른 기준축 사용
        if abs(np.dot(s_hat, reference)) > 0.99:
            reference = np.array([0.0, 1.0, 0.0])

        h_hat = unit(np.cross(s_hat, reference))
    else:
        h_hat = unit(h_hat)

    # 궤도면 불일치
    if not np.isclose(np.dot(s_hat, h_hat), 0.0, atol=1e-8):
        raise ValueError(
            "h_hat must be perpendicular to vinf_dep_vec "
            "for a coplanar parking-orbit injection."
        )

    r_p = R_EARTH + parking_alt_km

    # 쌍곡선 궤도 요소
    e = 1 + r_p * vinf**2 / MU_EARTH
    f = np.arccos(-1 / e) # 진근점이각

    # 근지점 벡터 계산
    r_hat_p = rodrigues(s_hat, h_hat, -f) # 속도벡터 회전 -> 근지점 설정
    t_hat_p = unit(np.cross(h_hat, r_hat_p)) # 위치벡터 구하기
    v_hyp_p = np.sqrt(vinf**2 + 2 * MU_EARTH / r_p) # 속도 구하기
    v_circ = np.sqrt(MU_EARTH / r_p) # 케플러 속도

    r_p_vec = r_p * r_hat_p # 근지점 위치벡터
    v_hyp_p_vec = v_hyp_p * t_hat_p # 쌍곡선궤도 속도벡터
    v_parking_vec = v_circ * t_hat_p # 주차궤도 속도벡터
    delta_v_tmi_vec = v_hyp_p_vec - v_parking_vec # injection 시 Delta V

    return {
        "r_p_km": r_p_vec,
        "v_hyp_p_km_s": v_hyp_p_vec,
        "v_parking_km_s": v_parking_vec,
        "delta_v_tmi_km_s": delta_v_tmi_vec,

        "r_p_norm_km": np.linalg.norm(r_p_vec),
        "v_hyp_p_norm_km_s": np.linalg.norm(v_hyp_p_vec),
        "delta_v_tmi_norm_km_s": np.linalg.norm(delta_v_tmi_vec),

        "vinf_norm_km_s": vinf,
        "eccentricity": e,
        "f_inf_deg": np.degrees(f),
        "h_hat": h_hat,
    }
```

주차궤도는 고도 200km의 LEO로 설정하였다. 그러나 이를 통해 출력된 값을 그대로 초기값으로 하여 수치적분하기에는 지구와 너무 가까워 문제가 있었다. 이를 해결하기 위해 우선 지구의 SOI까지 전파시킨 결과, JD 2487524.732412126381에 SOI에 도달하는 것으로 분석되었으며, 이 시점을 기준 시간으로 잡았다.
